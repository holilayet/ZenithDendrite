# ZenithDendrite

This project provides a simple, extensible workflow management system for distributed projects and teams.

ZenithDendrite is a tool designed to simplify project management for open-source developers. It allows multiple contributors to collaborate on tasks and projects, track progress, and assign responsibilities. By using ZenithDendrite, teams can improve communication, reduce errors, and increase productivity.

## Key Features

- **Task management**: Assign and track tasks, set deadlines, and monitor progress.
- **Collaborative interface**: Multiple users can contribute to and view project information in real-time.
- **Customizable workflows**: Create custom workflows to suit project needs.

## Technology Stack

- Python
- Django framework
- Pytest testing tool

## Installation

1. Clone the repository: `git clone https://github.com/holilayet/ZenithDendrite.git`
2. Install the required packages: `pip install -r requirements.txt`

## Configuration

To configure ZenithDendrite, you can modify the settings in `settings.py`. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
